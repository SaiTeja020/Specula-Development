Scope and provenance
Only the workflow registered by build_graph() is included. Ingestion services, database infrastructure and standalone helper agents are not inserted as fictional workflow nodes. Source code, rather than historical model assignments or feature targets, defines the inventory.
Node execution can mix deterministic analysis, structured model review and guarded compatibility paths. Model choices are runtime configuration; this export does not assert live model readiness or measured forensic accuracy.
